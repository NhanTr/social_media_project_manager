## Defects corrected

- Feed absence detection now uses the server's complete cursor ordering (`createdAt DESC, id DESC`). A valid same-timestamp post pushed to page two stays available.
- Cache reconciliation uses the complete response before applying the twenty-preview bound. An older valid post is not falsely revoked by the bounded preview write.
- Every relevant filter snapshot is reconciled against a fresh page, including partial pages. Authoritative deleted/blocked content cannot return from another filter offline.
- Open media detail rechecks its API permission on feed changes, including when the post lies outside the current page.
- Android native picker recovery has a durable account/operation owner marker written before opening the picker. App-global lost results without that owner are drained without displaying or persisting their bytes in another account. Legacy unowned results are deliberately discarded.
- Antigravity's permission/recovery guidance, expired upload reconciliation, and shell session changes are retained and covered by the expanded suite.

Each newly identified product defect was reproduced by a failing test before its fix. A separate read-only reviewer identified the partial-page cross-filter cache and app-global picker ownership defects; both were fixed in the same review pass. No deferred Critical, Important, or Minor findings remain from that review.

## Reproduce

From `loccoc_application/`:

```sh
dart format --output=none --set-exit-if-changed lib test integration_test
flutter analyze
flutter test --coverage --timeout 30s
flutter test integration_test/permission_denied_smoke_test.dart -d DEVICE --no-uninstall --timeout 90s
flutter test integration_test/live_backend_s2_e2e_test.dart -d DEVICE --no-uninstall --dart-define=API_BASE_URL=http://localhost:8080 --timeout 150s
```

For iOS denied Photos, set `EXPECT_PHOTOS_DENIED=true` and revoke camera/photos-add for `com.example.loccocApplication` before running; grant photos-add before the live E2E. On Android, fix the camera permission to denied for the permission test. API 35 adds images to MediaStore without requesting broad Photos read permission. Android needs `adb reverse tcp:8080 tcp:8080` and `adb reverse tcp:9000 tcp:9000` for this localhost QA stack. Run device suites sequentially to avoid shared Flutter runner startup contention.

From the repository root:

```sh
python3 scripts/check_s2_process_restart.py DEVICE
```

This waits for `S2_RESTART_READY` after actual app-sandbox draft/cache writes, terminates the real app with `simctl terminate` or `am force-stop`, and rebuilds/relaunches with `--no-uninstall`. The interrupted writer's nonzero test exit is expected; the separate recovery phase must pass. Flutter's default integration-test uninstall would destroy the sandbox and cannot be used for this check.

Local logs are in `/private/tmp/loccoc-s2-*.log`; restart logs are in the temporary directory printed by the process-restart script. Test logs contain no access tokens or OTPs. No shared database/volume was removed, and no migration was edited.
